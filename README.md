# Mini App Engine v0.1

Статический MVP базового движка без серверов, API, npm и внешних библиотек.

Файлы:
- index.html — входная страница
- engine.css — общий интерфейс
- engine.js — базовый движок
- config.js — тема и настройки
- demo.js — демонстрационный сценарий

Demo проверяет:
START → CHOICE/свой вариант → DUEL → ELIMINATE → MESSAGE → RESULT,
а также localStorage, историю действий, модальное окно, restart и share.

Для скрытой тестовой кнопки добавьте к URL: ?test=1
